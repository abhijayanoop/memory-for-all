title: Picking a database for the budgeting app

**User:** I'm building a budgeting app called PennyPilot. Which database should I use?
**Assistant:** For a solo project with relational data like accounts and transactions, I'd suggest Postgres.
**User:** Decision: I'll go with Postgres hosted on Supabase for PennyPilot.
**Assistant:** Good choice. Supabase also gives you auth and row level security out of the box.
**User:** How should I model recurring transactions?
**Assistant:** Use a recurring_rules table with a cron-style schedule and generate transactions nightly.
